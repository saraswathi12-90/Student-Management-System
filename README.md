# Student Management System

## Project Description
A Python-based Student Management System that helps users manage student information and academic marks.

## Features
- Add student details
- View all students
- Search students by name
- Update student details and marks
- Delete student records
- Calculate total marks and percentage
- Calculate Pass/Fail status
- Generate grades
- Validate marks between 0 and 100
- Save student records using JSON

## Technologies Used
- Python
- JSON
- VS Code

## How to Run

1. Install Python.
2. Download or clone this project.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

```bash
python student_management.py
```

## Project Output
The program displays a menu to add, view, search, update and delete student records.
